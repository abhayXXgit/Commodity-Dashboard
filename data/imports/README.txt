Drop OFFICIAL producer price circulars in THIS folder.

  - Put the producer's name in the filename:  nalco_2026-09.xlsx
  - .xlsx, .xls and .csv are all read
  - Press "Refresh data" in the dashboard, or wait for the 06:30 daily job

Files here are imported as VERIFIED_HISTORICAL and will override demo data,
so only put genuine published circulars here.

Anything whose name contains sample / example / template / demo / test / mock
is deliberately IGNORED, so that a format demonstration can never be recorded
as a real price under a producer's name.

See examples/circular_format_EXAMPLE.xlsx for the expected column layout.
Its numbers are invented and it is excluded from import by that rule.
